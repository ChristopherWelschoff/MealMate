# Meal Mate

Meal Mate is a recipe app for discovering, creating and saving meals. Browse recipes from the community, add your own, and get nutrition values estimated automatically.

## Features

- **Browse recipes** – search and filter by category
- **Recipe details** – ingredients, step-by-step instructions, cooking time, image and nutrition info
- **Create and manage your own recipes** – add, edit and delete recipes, and reorder instruction steps
- **Image upload** – add a photo to your recipe
- **Automatic nutrition info** – calories, protein, carbs and fat are estimated from the ingredients using AI
- **Favorites** – save recipes you like and find them again quickly
- **Copy recipes** – take a recipe you like as a private copy and adjust it to your taste
- **Private recipes** – keep recipes just for yourself
- **Moderation** – new public recipes are reviewed by an admin before they go live
- **Google sign-in** and a personal profile
- **Dark and light mode**

## Built with

Next.js, React, TypeScript, Tailwind CSS, MongoDB, NextAuth, Cloudinary and Google Gemini.
